            <img src="/images/Group_Former.png" class="card-img-top" alt="Group Former", style="max-height: 75vh">
            <p>
                For the fourth hackathon we used an automated group formation tool that used the participants' pre-questionnaire responses to create and propose teams. The repository can be found <a href="https://github.com/HackEDX-Framework/group_former">here </a>. More information about the group formation can be found in the following publications: 
                <ul>
                    <li>Schulten, C., Nolte, A., & Chounta, I.-A. (2025). HackEDX: Towards a Methodological Framework for Hackathons as Educational Experiences. [Publication pending]</li>

The repository can be found <a href="https://github.com/HackEDX-Framework/ArcadeMachine">here </a>. More information about the group formation can be found in the following publications:
